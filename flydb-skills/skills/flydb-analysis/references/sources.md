# 材料与工具接入

## 从现有能力开始

| 可用材料 | 立即可以做的工作 | 需要明确的限制 |
|---|---|---|
| 项目目录及自然语言变更 | 搜索、读取和关联应用引用 | 数据库对象与当前状态未核验 |
| DDL、对象定义或结构快照 | 分析材料内的表/列/视图等关系 | 来源、时间、完整性和目标环境可能未知 |
| 已配置并获授权的数据库工具 | 获取目标元数据、对象定义及数据库返回的依赖 | 权限、schema 和对象类型决定可见范围 |
| 用户提供的 Flydb dry-run JSON | 消费其中的变更语句和计划标识 | 不是完整数据库快照；SQL 可能已脱敏 |
| 少量粘贴片段 | 对明确可见的关系给出局部结论 | 无法据此评价整个仓库或生产环境 |

仅缺某一种材料时继续其他部分。按入口所选流程判断最小输入；快照与漂移不要求拟议变更，依赖和引用查询只需对象或限定范围。该流程完全没有可读取材料，或所需对象无法辨认时才标为 blocked，并给出最小补充要求。

## 宿主能力探测

先使用本次会话真实暴露的文件、搜索和数据库能力。MCP 的工具名和参数从工具描述中发现，不假定某个数据库服务已安装，也不虚构 `flydb_snapshot`、`execute_sql` 等入口。

- 已有结构化元数据工具优先于临时拼装查询。工具缺少定义读取能力时，建议用户提供相关 DDL；它不会阻断代码部分。
- 在已授权、已连接且支持 SQL 的工具上读取元数据时，核对产品/版本、schema 和目录视图语义；查询失败、权限不足、结果分页或截断都要进入覆盖记录。
- 只把当前调用实际可见的事实作为证据。MCP 的 `readOnlyHint` 是提示，执行前仍需理解工具作用。
- 没有网络时不阻塞本地调查。使用本地版本匹配文档；无法确认的厂商语义标为待核验，不按近似家族直接推定。

## 数据库身份与事实边界

分别记录已知的产品、版本、catalog/schema、对象引号、登录用户与目标 schema。只取得部分信息时原样保留，不填猜测值。

Oracle 家族场景尤其注意当前 schema 与登录用户未必一致，以及目录视图受 owner/权限影响。按目标产品的已核实文档选择字典信息。厂商家族相近不意味着列改名、类型转换或依赖失效行为完全一致。

快照来源由提供者说明；没有采集记录时写“用户提供的定义，采集时间未知”。只包含表结构的文件不能证明没有视图、过程或触发器。

对比两个材料时，先核对环境、时间、对象范围和名称规则。条件不可比时报告“资料不一致，原因待核验”，不能直接宣布生产漂移。

## 可选 Flydb 接入

已有 Flydb 计划时，读取成功信封、实际 SQL 与 script/line 信息，引用 `plan.algorithm` 和 `plan.id`。保留计划源文件或工具调用标识；不要把分析结论拼入计划摘要或从脱敏 SQL 重算 ID。

需要现场取得 Flydb 计划且已有授权时，先读取该安装版本的 CLI Skill/参考文档并核对版本，再按真实命令能力调用。现有 Flydb MCP 只提供迁移相关工具，不能假定它能枚举全部数据库结构。CLI 或 MCP 缺失时仍可分析已有代码、SQL和快照。

用户提供的任意 SQL 文件不必转换为 Flydb 命名规则，也不必创建迁移历史、baseline 或 flydb.conf。

## 记录来源与失败

文件证据记录工作区标识、相对路径、行号和最小片段；输出可点击链接时按宿主要求提供可访问的绝对路径。

工具证据记录工具、目标身份、查询/读取范围、时间及结果位置；只写实际可获取的字段。工具没有调用 ID 时用报告内证据编号关联结果摘录，不伪造平台 ID。

大项目可分批处理；记录已处理分区和未处理分区。查询超时或读取截断不等于结果为空；确需扩大访问范围的部分保留为未知，已经取得的证据仍可交付。
